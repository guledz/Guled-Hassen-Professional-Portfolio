GITHUB PAGES DEPLOYMENT
-----------------------
The website does not require a build system.

Recommended repository structure:

guled-hassen-portfolio/
└── index.html

Deployment steps:

1. Create a GitHub repository.
2. Rename the downloaded HTML file to index.html.
3. Upload index.html to the repository root.
4. Commit the file.
5. Open Settings → Pages.
6. Select deployment from the main branch.
7. Select / (root).
8. Save.

GitHub Pages can then serve the portfolio as a static website.


SELF-CONTAINED FILE
-------------------
The current HTML is designed as a single self-contained website.

The current portfolio imagery is embedded directly into the HTML, so an additional image folder is not required for this version.

This reduces the risk of broken image paths during GitHub Pages deployment.
